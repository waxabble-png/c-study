# C 语言练习

北京林业大学大一 C 语言课程练习代码，按日期分目录存放。

## 源码清单

| 文件 | 作用 |
| --- | --- |
| `2026_9_16zcode/输出个人信息.c` | 用 printf 输出姓名、年龄、身高 |
| `2026_9_16zcode/摄氏转华氏温度.c` | 输入摄氏温度，换算成华氏温度 |
| `2026_9_16zcode/三位数逆序输出.c` | 输入三位数，逆序输出（123 → 321） |
| `2026_9_16zcode/金额拆分纸币张数.c` | 输入金额，算出 100/50/20/10/5/1 元各需几张 |
| `2026_9_16zcode/字母大小写与ASCII转换.c` | 小写转大写、求字母序号、偏移三位 |
| `2026_9_16zcode/格式化宽度输出.c` | 姓名/年龄/成绩按指定宽度对齐打印 |
| `2026_09_20/弹窗思念小程序.c` | MessageBox 弹窗小程序（另含大量注释掉的基础练习） |
| `2026_09_22/猜数字游戏.c` | 猜 1~100 的数字，共 6 次机会 |
| `2026_10_04/猜数字游戏_带计时.c` | 猜 1~100 的数字，共 10 次机会并统计用时 |

## 编译运行

用 GCC（MSYS2 UCRT64）编译单个文件：

```bash
gcc 2026_10_04/猜数字游戏_带计时.c -o game.exe -Wall
./game.exe
```

用 Visual Studio / VS Code 打开`.c`文件即可编辑；在本机用 Visual Studio 建工程调试时，工程文件（`.slnx`、`.vcxproj`）只保存在本地，不纳入仓库。

> 仓库已通过 `.gitignore` 排除 `.vs/`、`x64/`、`*.exe`、`*.slnx`、`*.vcxproj` 等编译产物与工程配置，**只保留 `.c` 源码**。克隆下来后直接用 GCC 编译即可运行。
