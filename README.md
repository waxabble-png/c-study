# C 语言练习

北京林业大学大一 C 语言课程练习代码，按日期分目录存放。

## 目录结构

| 目录 | 内容 |
| --- | --- |
| `2026_9_16zcode/` | 基础语法练习（`1.c` ~ `6.c`） |
| `2026_09_20/` | 练习 |
| `2026_09_22/` | 猜数字 |
| `2026_10_04/` | 练习的小游戏（猜 1~100 数字，带计时） |

## 编译运行

用 GCC（MSYS2 UCRT64）编译单个文件：

```bash
gcc 2026_10_04/练习的小游戏.c -o game.exe -Wall
./game.exe
```

用 Visual Studio 打开对应目录下的 `.slnx` 即可直接编译调试。

> 仓库已通过 `.gitignore` 排除 `.vs/`、`x64/`、`*.exe` 等编译产物，只保留源代码与工程配置文件。
